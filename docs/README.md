# Документація проєкту claude-store

Інтернет-магазин на WordPress + WooCommerce. Ринок — Україна, одна мова (українська),
каталог 100–1000 товарів з варіаціями. Проєкт комерційний, під продакшн.

## Як цим користуватись

1. **CHECKLIST.md** — джерело правди про статус. Позначай `[x]`, коли пункт закрито.
2. **PROGRESS.md** — я оновлюю після кожної робочої сесії. Не переписуй історію, тільки додавай.
3. **DECISIONS.md** — щоразу, коли робимо неочевидний технічний вибір, туди йде запис.
   Через три місяці це заощадить години.
4. Якщо документ розійшовся з реальністю — правимо документ, а не вдаємо, що все гаразд.

## Легенда пріоритетів

🔴 **блокер** — без цього не запускаємось.
🟡 **важливо** — можна після запуску, але в перший тиждень.
🔵 **бажано** — коли буде час.

## Швидкий старт для нової сесії

```bash
cd "/Users/admin/Local Sites/claude-store/app/public/wp-content/themes/my-theme"
npm install          # один раз
npm run watch        # збірка SCSS у режимі спостереження
```

Сайт локально: Local by Flywheel → сайт `claude-store` → Open site.
